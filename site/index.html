O livro

Todo feitiço guarda
uma decisão.

Criar, combinar e distribuir ações pode decidir o destino de uma passagem, de uma família ou de uma cidade.

No mundo do Grimório do Código Limpo, dragões, guardiões e artesãos enfrentam problemas que a força sozinha não resolve. Os padrões de projeto ganham corpo em 23 contos autônomos, com magia como código e consequências para cada escolha.

Depois da história, experimente o mecanismo. Cada padrão tem um projeto independente em TypeScript, com código, testes, exercício e uma solução para comparar com a sua.
